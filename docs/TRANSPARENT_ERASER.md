# 투명 캔버스 · 지우개 · 설정

## 사용 방법

1. 앱/웹을 열면 새 캔버스는 투명(체크무늬)으로 시작합니다. 새 그림 대화상자도 투명이 기본이며, 필요하면 흰색을 선택합니다. 기존 프로젝트와 복구 문서는 바꾸지 않습니다.
2. 우측 **색상 · 브러시 → 지우개 설정**에서 `투명하게 지우기` 또는 `배경색으로 지우기`를 고릅니다. 배경색 모드에서는 바로 아래 색상을 선택합니다. 작은 화면에서는 상단 팔레트 버튼으로 패널을 엽니다.
3. 지우개(E)로 그리면 활성 레이어에 적용됩니다. 레이어 개수와 관계없이 같은 모드를 사용하며, 아래 레이어는 유지됩니다. 투명하게 지워도 아래 레이어가 있으면 그 내용이 보입니다.
4. 둥근 지우개는 불투명도·경도에 따라 부분적으로 지우며, 사각 지우개는 선명하게 지웁니다. 획 도중 표시와 최종 픽셀은 같은 엔진/설정을 사용합니다. 실행 취소·다시 실행이 가능합니다.
5. 지우개 모드와 색상은 이 브라우저/앱의 로컬 설정으로 저장합니다. 저장소가 차단되면 이번 세션에만 적용합니다. 문서의 지우기/확장 바탕과 별개이며, 색상 지우개(전경색 치환) 도구는 변경하지 않습니다.
6. 상단 **설정**, 또는 메뉴의 **테마 · 환경설정**에서 스킨을 변경합니다. 좁은 화면에도 설정 글자 버튼이 남습니다.

## 검증 범위 (2026-11-12)

- Node 346개: 모드·색상 검증, 단일/다층, 둥근/사각, 취소·Undo/Redo·프로젝트 알파 보존 포함.
- TypeScript·Prettier·Vite 빌드 통과.
- `npm run test:eraser-settings`는 실제 UI 입력·저장·재시작·좁은 화면을 확인하는 추가 회귀 테스트입니다. 이 환경에서는 Chromium 실행 제약으로 미완료입니다.
- Windows/macOS 실물 앱 빌드·파일 대화상자·IME·PNG 출력·펜/HiDPI 및 서명/공증은 지원 호스트에서 남은 검수입니다. Linux 단위 테스트를 OS 실검수로 간주하지 않습니다.
