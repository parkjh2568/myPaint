# 출력 미리보기 구현과 검증

2026-11-06. [소스·검증·독립 리뷰 근거](../evidence/studio-output-preview.json). QF-17의 미리보기 구현 단계이며 전체 전환이나 출시 완료 선언은 아니다.

## 변경 결과

내보내기 창에서 PNG 투명도와 JPG/BMP 바탕색을 확인할 수 있다. 이동·붙여넣기 중인 선택, 편집 중인 문자, 미확정 곡선·다각형도 활성 레이어 안에서 합성한다. PNG에서는 바탕색 조작을 비활성화하고 값을 보존하며, JPG/BMP로 돌아가면 이전 선택 색을 재사용한다. 체커보드와 스킨은 출력 파일에 포함하지 않는다. JPEG의 손실 압축과 축소로 인한 세부·경계 차이는 창 안에 안내한다.

미리보기 backing은 각 축 최대 192px이며 작은 그림의 backing은 확대하지 않는다. CSS 표시만 비율에 맞춰 확대해 작은 그림도 확인할 수 있게 했다. 실제 390px Classic 98 화면에서 회색 확인 버튼에 흰 글자가 남는 기존 공통 CSS 충돌을 발견해 스킨의 글자 토큰을 적용했다. 준비 완료 버튼의 실제 대비는 10.46:1이다. 전체 접근성 인수로 확대하지 않는다.

## 구조와 데이터 흐름

소유 함수 `exportImage`가 대화상자, 채널, 대기 중인 폰트, 축소 RGBA, 취소와 정리를 관리한다. 미리보기 준비에는 전체 `cloneState`·`pendingState`·`composite`나 코덱 Worker를 호출하지 않는다. 각 visible 레이어에서 축소 격자의 원본 좌표만 읽고 활성 레이어에는 원본 영역 지우기 → 선택 payload → 문자 → 도형을 적용한다. 확장 영역은 기존 resize 정책대로 첫 레이어에 문서 바탕, 나머지에는 RGBA 0을 적용한다. 활성 레이어 위의 레이어도 원래 순서와 단계별 정수 반올림으로 합성한 뒤 최종 바탕색을 적용한다.

최종 RGBA를 캐시하므로 형식·바탕색 변경은 작은 버퍼만 다시 표시한다. 문서·revision·활성 레이어·세대·pending 소유권이 달라지면 오래된 결과를 내보내지 않는다. 취소는 폰트 대기와 채널 waiter를 깨우고 generator·Surface를 정리한다. 미리보기 실패는 이전 그림을 지우고 오류를 표시한다. 사용자가 확정해야 기존 전체 후보 생성·실제 export 경로가 실행된다.

공유 의미가 있는 문자 배치와 그리기만 `textLayoutSteps`·`paintText`로 나눴다. 실제 문자 출력도 같은 원래 글꼴·codepoint 줄바꿈·스크롤·RGBA·512 타일 정책을 사용한다. 그 밖의 순차 작업은 소유 함수 안에 두었다. 실제 도형 그리기 `paintShape`와 기본 Surface 정책은 재사용하며 readback hint를 추가하지 않았다.

[최신 의존성 그래프](../evidence/studio-output-preview-module-graph.json)는 TS 노드 13개·선언 35개·관계 34개, 소스 런타임 순환 0개다. 배포 JS 5개·관계 6개는 정적 평가 순환과 top-level await가 없고 동적 SCC는 기존 2개다. 런타임 17개 중 main과 CSS만 변경했다. Studio 멤버 131→133, 기존 메서드 변경은 textRaster/dialog/exportImage 3개이며 신규 모듈·의존성·Rust 변경은 없다.

| 형식·타입·빌드 | 최종 Prettier·tsc·Vite·Studio manifest·macOS 앱 빌드 통과 |

4096² 두 레이어 문서에서 미리보기 소유의 신규 RGBA backing 두 개는 각각 147,456B, 추가 코덱 작업은 0이었다. 같은 시간에 실행된 기존 타일 렌더러의 15개 할당은 호출 스택과 실제 non-preview Offscreen receiver로 구분해 원문에 함께 보존했다. 전체 화면의 모든 할당이 192px 이하라는 주장은 하지 않는다. 도형/문자 overlay까지 포함한 숫자 plane의 설계 상한은 442,368B이며 Canvas 내부·경로·글꼴·문자열·원본·RSS는 별도다. 256 codepoint/16행 양보가 모든 native 호출의 50ms 제한이나 p95를 보장하지 않는다.

처음 확장 검사에서 나온 2개 실패도 보존했다. 다각형은 채움색이 기본 흰색이었고 실제 PNG와 미리보기 모두 흰색이었다. 큰 문서 검사는 기존 타일 할당을 미리보기 할당으로 세었다. 의도한 보조색 설정과 스택/receiver별 원장으로 검사를 교정했으며 미리보기 상한이나 픽셀 기대값을 낮춰 통과시키지 않았다. 별도 코드 리뷰의 최종 범위에는 추가 Blocker/Major/Minor가 없다.

## 산출물과 다음 작업

최종 웹 payload는 LICENSE 포함 9파일·283,019B다. 원래 276,616B에서 6,403B 늘었으며 SDK·node_modules·Rust target·소스는 포함하지 않는다. 검증 manifest는 후속 빌드로 덮이지 않도록 phase의 `final-bundle`에 고정했다. 실제 홈페이지 저장소에는 쓰지 않았고 커밋·푸시·공개 배포도 수행하지 않았다.

QF-17 체크박스와 전체 감사 6개 입증·26개 부분·2개 미구현은 유지한다. 선행/플랫폼 게이트까지 닫힌 항목은 QF-01뿐이다. 다음 구현 우선순위는 실제 48px 조작 표적의 CSS 충돌, 가상 키보드·회전 중 pending 보존, 미변형 선택 확정의 전체 복사 비용이다. 물리 Android 웹·Windows 패키지·OS 파일/IME·실제 WK/Safari의 미리보기 전체 조합·최대 축/16레이어·장기 RSS와 출시 게이트는 남는다. 모바일·태블릿은 웹 전용, 실행 파일은 Windows/macOS 전용을 유지한다.
