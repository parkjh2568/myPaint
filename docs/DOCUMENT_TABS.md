# 메뉴와 여러 그림 탭

- 상단 메뉴를 열면 **파일 / 편집 / 이미지 / 레이어 / 설정 / 도움말** 범주를 선택합니다. 테마와 글꼴, 문서 바탕은 설정에 있습니다.
- **열기**와 **새 그림**은 현재 그림을 지우지 않고 새 탭을 만듭니다. 사진 삽입은 현재 탭에 추가합니다.
- 탭을 클릭해 전환합니다. 각 그림의 레이어, Undo/Redo, 확대·이동, 저장 대상은 독립적입니다. 전환 전 미확정 선택·문자는 현재 그림에 확정됩니다.
- 웹 파일 선택기는 여러 파일을 한 번에 선택할 수 있습니다. 앱에서는 열기를 반복해 여러 탭을 엽니다.
- 현재 탭에서 프로젝트 저장/이미지 내보내기를 실행합니다. 프로젝트는 `.rpaint`, 이미지 저장은 내보내기를 사용합니다. 웹은 다운로드이며 실제 파일 보관을 확인해야 합니다.
- 탭의 ×로 닫습니다. 편집된 그림은 저장/버리기/취소를 묻습니다. 앱 종료 시 모든 탭의 변경을 확인하고, 웹 종료 시 변경된 탭이 있으면 브라우저 경고를 요청합니다.
- 최대 12탭. 새 탭을 여는 시점에 보존 중인 픽셀·이력과 입력 픽셀 합계 512 MiB 한도를 검사합니다. 이후 편집에는 기존 문서별 자원 제한이 적용되며, 이것은 전체 앱 RSS 제한이 아닙니다.
- 탭 목록 자체를 재시작 시 자동 복원하지는 않습니다. 편집된 그림의 복구 사본은 파일 → 복구 사본에서 다시 열 수 있습니다.

## 검증

`node --import tsx --test tests/document-tabs.test.ts`: 문서별 픽셀/이력/뷰 상태, 전환 실패 보존, 작업 중 전환 차단, 닫기 취소, 범주 분류.

`npm run test:document-tabs`: 브라우저에서 네이티브 저장 경계를 모델링한 탭/메뉴/저장 경로 검사. 실제 OS 파일 대화상자 검증을 대체하지 않습니다.

Rust persistence에 문서 key별 저장 경로 복원 단위 테스트를 추가했습니다. 지원 OS에서 Rust 테스트와 앱 검수를 수행해야 합니다.
